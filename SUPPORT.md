# Support

Community support is provided through GitHub issues on a best-effort basis. The
project currently has one active maintainer, so response targets are not service
level agreements.

## Where to ask

- Use the bug form for a reproducible defect with redacted evidence.
- Use the feature form for a scoped capability request.
- Use the RFC form for protocol, privacy, security, platform, governance or other
  material compatibility changes.
- Use a private GitHub security advisory for vulnerabilities.

Include Observer version, Node/pnpm, host OS, React Native/Expo, exact Android/API
fixture, commands, expected/actual outcome, evidence source and every unverified
boundary. Do not upload credentials, production traffic bodies, account data,
SQLite stores, unredacted screenshots, APK signing material or live active-policy
files.

## Response targets

- Security report acknowledgement: target three business days.
- Reproducible regressions on the latest release: target initial triage in seven
  days.
- Feature/RFC discussion: no guaranteed response time; priority follows safety,
  evidence integrity, compatibility impact and available maintainers.

Only the latest npm release is supported. Runtime claims apply solely to fixtures
listed as verified in `docs/testing.md` and `docs/compatibility.md`.
